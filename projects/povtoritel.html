Povtoritel

A Windows application for instant replay and continuous screen recording. It keeps recent footage in RAM, saves it to MP4 on demand, and runs locally from the system tray.

Python Windows FFmpeg Desktop Duplication hardware encoding local-only
View on GitHub ↗

What it does

local capture

Replay and recording from one capture pipeline

Povtoritel keeps the last one to ten minutes in RAM and saves the buffer to MP4 with a global hotkey. The same pipeline can record continuously when needed.

Instant replay

  • one to ten minute RAM buffer
  • save after the moment has happened
  • NVIDIA or AMD hardware encoding

Continuous recording

  • start and stop with a global hotkey
  • desktop, microphone, and per-app audio
  • local MP4 output from the system tray
