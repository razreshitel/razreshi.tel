Povtoritel

A Windows application for instant replay and continuous screen recording. It keeps the selected time window in RAM, saves it to MP4 on demand, and runs quietly from the system tray. Capture, encoding, audio, and file output stay on the local machine.

Python Windows FFmpeg Desktop Duplication hardware encoding local-only
View on GitHub ↗

What it does

04 features
01 Replay

Save the last few minutes

Povtoritel continuously keeps a configurable one to ten minute window in RAM. A global hotkey writes the current buffer to MP4, so the moment can be saved after it has already happened without recording the entire session to disk.

02 Record

Switch to continuous capture

A second hotkey starts and stops a normal long recording. It can also be activated by holding the replay hotkey for two seconds, which keeps both capture modes available without opening the tray menu.

03 Audio

Keep useful audio tracks

Desktop audio and microphone input are configurable. Automatic per-application tracks separate active programs by executable name, while silent tracks are removed from the saved file.

04 Control

Stay out of the way

The tray icon shows whether buffering is active, paused, or recording. Settings apply without restarting the application, on-screen notifications appear on the selected display, and those notifications are excluded from capture.

The constraint

local capture

The recording never needs a cloud service

The application is a direct Windows capture pipeline. Recent footage lives in memory, hardware encoding happens on the GPU, and requested recordings are written to a folder selected by the user.

Runs on the PC

  • screen capture and H.264 encoding
  • RAM replay buffer
  • desktop, microphone, and app audio
  • tray controls and global hotkeys

Not required

  • cloud recording account
  • remote upload service
  • browser extension
  • game-specific integration
