PROJECT / canvas-tool-local

Canvas

A self-hosted visual workspace for notes, tasks, files, diagrams, tables, charts, and nested boards. It runs directly on Node.js and keeps account, workspace, sharing, and upload data on your own server.

What it does

05 systems
01 Workspace

Arrange ideas on an infinite canvas

The workspace supports zooming, panning, multi-selection, snapping, undo, and redo. Boards can be nested with their own icons, breadcrumbs, browser history, and an Unsorted inbox for new material.

02 Objects

Mix structured and visual content

Notes, to-do lists, documents, links, files, media, maps, sketches, tables, charts, arrows, comments, columns, and folder shelves all live on the same board. Rich previews cover text, source code, books, PDFs, Office files, images, video, and audio.

03 Find

Keep a large workspace navigable

Indexed search, a command palette, Trash, resumable uploads, and bounded revision history make the workspace recoverable and quick to navigate. Boards can be exported to PNG, PDF, Markdown, text, JSON, or ZIP.

04 Share

Share only the board that matters

Accounts stay private by default, with per-board access for other users. Workspace changes update live across browser tabs and between authorized users without exposing the rest of the account.

05 Operate

Run it as a small self-hosted service

Canvas runs as a native systemd service behind Caddy HTTPS. Atomic releases, health checks, rollback, storage maintenance, and verified daily backups keep the Raspberry Pi deployment practical to operate.

The constraint

owned infrastructure

The server owns the workspace data

Application state, accounts, uploads, sharing rules, and backups are managed by the Canvas host. The browser receives the workspace UI, while sensitive storage and internal service endpoints remain behind authenticated routes and the HTTPS reverse proxy.

Kept on the host

  • SQLite workspace and account data
  • uploaded files and per-account quotas
  • sharing rules and session state
  • backups, releases, and diagnostics

Not exposed directly

  • SQLite database files
  • the raw upload directory
  • the localhost application port
  • sensor API credentials
