Povtoritel

Приложение для мгновенных повторов или непрерывной записи. Последние минуты хранятся в оперативной памяти и сохраняются глобальной горячей клавишей. Ключевые функции - разделение потоков аудио, отсутствие лишних функций, гибкая настройка.
Текущая реализация только для Windows

Python Windows FFmpeg Desktop Duplication Аппаратное кодирование Полностью локально
Открыть на GitHub ↗

Функции

локальный захват

Повтор и запись из одного конвейера захвата

Povtoritel хранит последние 1-10 минут в оперативной памяти и сохраняет буфер в MP4 глобальной горячей клавишей. При необходимости тот же конвейер ведет непрерывную запись.

Мгновенный повтор

  • сохранение 1-10 минут в буфер для быстрого повтора
  • регулировка системных ресурсов
  • возможность выбора битрейта
  • раздельные каналы аудио для кажого источника

Непрерывная запись

  • запуск и остановка глобальной горячей клавишей
  • звук рабочего стола, микрофона и отдельных приложений
  • локальная запись MP4 с управлением из системного трея

Настройки

приложение Windows
Платформа
Windows 10 or 11, Python 3.12 или новее
Захват
FFmpeg Desktop Duplication, один выбранный дисплей
Кодирование
NVIDIA NVENC or AMD AMF, аппаратное кодирование H.264
Повтор
1-10 минут в оперативной памяти, сохранение MP4 по запросу
Частота кадров
30, 60, 120 или 144 FPS
Звук
микс рабочего стола, микрофон и дорожки отдельных приложений
Управление
системный трей, глобальные горячие клавиши и автозапуск, автоматическое восстановление после отключения дисплея
