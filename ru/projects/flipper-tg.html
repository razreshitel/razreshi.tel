ПРОЕКТ / flipper-tg

Мост Telegram для Flipper Zero

Чтение и отправка сообщений Telegram прямо с экрана Flipper Zero. Сервер с FastAPI на Raspberry Pi связывается с приложением FAP через Wi-Fi-мост на ESP32.
Приложение на Flipper поддерживает экранную клавиатуру, транслитерацию кириллицы, постраничные чаты и имеет полное end-to-end шифрование сообщений.

Все сообщения, доступные боту, сохраняются в базе данных сервера.
Трафик между сервером и Flipper шифруется общим секретом. Веб-интерфейс позволяет просматривать и удалять сохраненные сообщения.
Если доступ к Telegram обычно заблокирован, VPN будет нужен только на сервере.

C (Flipper FAP) Python / FastAPI SQLite ESP32 Raspberry Pi
